# Contributing

## Pull Requests

Use a semantic title for every pull request. The title must follow the
Conventional Commits format:

```text
<type>(<scope>): <description>
```

The scope is optional:

```text
<type>: <description>
```

Examples:

```text
feat(cli): add page archive command
fix(config): reject invalid site URLs
docs: update install instructions
```

## Commit Messages

Use the same semantic Conventional Commits format for commit messages:

```text
<type>(<scope>): <description>
```

Common types include `feat`, `fix`, `docs`, `test`, `refactor`, `chore`, and
`ci`.

Keep the description concise, imperative, and specific.
